# 定位控制台 · Location Console

通过 Mac 的 Xcode 开发服务，为 USB 连接的 iPhone 设置固定位置或播放 GPX 路线。

**提供编译好的 Mac 软件包。需要兼容的完整 Xcode；无需自行编译，也无需 Python 或 Codex。**

当前版本：**v1.3.0-beta.1** · Apple Silicon · MIT

> 当前是预发布版，尚未完成另一台干净 Mac 上的首次安装体验验收。接口检查通过不等于所有 iPhone / iOS 组合均已验证。请先查看[兼容范围](docs/COMPATIBILITY.md)。

## 下载与开始

1. 打开 [v1.3.0-beta.1 下载页](https://github.com/y1yiii/location-console/releases/tag/v1.3.0-beta.1)，或[直接下载 Mac 软件包](https://github.com/y1yiii/location-console/releases/download/v1.3.0-beta.1/LocationConsole-v1.3.0-beta.1-macOS-arm64.zip)。
2. 下载 `LocationConsole-v1.3.0-beta.1-macOS-arm64.zip`，解压，将「定位控制台.app」整体放到「应用程序」。GitHub 自动生成的 `Source code.zip` 是源码，普通用户不用下载它。
3. 安装并手动打开完整 [Xcode](https://developer.apple.com/xcode/)，完成其首次许可与组件准备。
4. 打开定位控制台，进入 **环境检查**，点击「检查环境与设备」。按提示完成 Xcode 和 iPhone 准备。
5. USB 连接 iPhone，解锁、信任 Mac、开启开发者模式，再刷新设备。
6. 设置固定坐标，或导入 GPX 到「我的路线」后开始回放。结束后点击「停止并清除」，并在手机地图确认真实位置恢复。

完整步骤见[首次配置](docs/INSTALL.md)，遇到问题见[常见问题](docs/TROUBLESHOOTING.md)。

## 使用方法

### 绘制、保存与播放路线

1. 在 [gpx.studio](https://gpx.studio/zh/app) 绘制路线，导出 GPX 文件；也可以使用已有的单段 GPX。
2. 在软件「路线回放」中导入 GPX（快捷键 `⌘O`）。导入后会保存到「我的路线」，下次直接点击「选用」；原文件移动或删除不影响已保存的路线。
3. 确认预览和总路程。默认总耗时按 **公里数 × 300 秒** 计算，例如 2 公里为 10 分钟，每公里显示 **5分00秒**。
4. 如需修改，在总耗时中输入 `11:30` 或 `690`，都表示 11 分 30 秒。软件实时显示修改后的每公里用时和平均速度；切换或重新选用路线会恢复默认配速。
5. 选择已连接的 iPhone，准备好需要观察定位的 App，再点击「开始单次回放」。点击后直接发送请求；只播放一次，到达后保持终点。原 GPX 时间戳不决定回放速度。
6. 结束观察或记录后，点击「停止并清除」，再在手机地图点「当前位置」，确认蓝点已回到真实位置。

删除路线：点击「我的路线」对应条目的删除按钮并确认。软件内副本会移到废纸篓，原始 GPX 不受影响；回放期间不能切换或删除路线。

### 设置固定位置

进入「固定定位」，分别填写 **WGS84 纬度、经度**，点击「应用固定坐标」。在手机地图点「当前位置」确认结果；使用完毕同样要停止并清除。固定位置接口不会提供路线移动速度。

### 常用操作

| 操作 | 入口 |
| --- | --- |
| 刷新设备 | 控制台「刷新设备」或 `⌘R` |
| 导入 GPX | 路线回放页面或 `⌘O` |
| 停止并清除 | 对应按钮或 `⌘.` |
| 排查环境 | 环境检查 → 检查环境与设备 |
| 提交问题信息 | 环境检查 → 导出环境报告 |

## 功能

- **环境检查**：自动寻找常见位置的 Xcode；读取版本、初始化状态及固定定位 / 路线 / 清除接口是否存在。
- **固定定位**：输入 WGS84 纬度与经度。
- **路线库**：导入单段 GPX，保存多条路线，点击选用或单独删除；原文件移动后仍可使用。
- **配速计算**：默认每公里 **5分00秒**，自动计算总耗时；手动改时长会实时更新配速和平均速度。
- **单次回放**：预计到达后保持终点，不自动循环；进度是本机时间估算。
- **停止与恢复**：发送清除命令，保存未清除会话，重开后提示处理。
- **问题反馈**：可导出不含路线坐标、设备名称或设备标识的环境报告。

## 运行条件与边界

- 当前二进制为 **Apple Silicon / arm64**，面向 Mac 控制 iPhone 的使用方式。
- 需要完整 Xcode，单独安装 Command Line Tools 不够。Xcode 本身也必须支持你的 macOS 和 iOS。
- 应用最低加载版本声明为 macOS 14；这不代表每台 macOS 14 的 Mac 都能安装提供所需接口的 Xcode。
- iPhone 需要解锁、信任、开发者模式。检查工具不会代替你接受许可、安装组件、重启或确认信任。
- 实测接口仍带软件模拟来源标记。第三方 App 是否认可轨迹或里程取决于其自身规则。
- 清除命令成功返回后，仍需在手机地图确认。拔线或退出软件不保证恢复真实位置。
- 当前发布包使用临时签名，未做 Developer ID 签名或 Apple 公证，首次打开可能受 macOS 安全检查限制，参见[安装说明](docs/INSTALL.md)。

## 本机数据与隐私

路线库和日志保存在 `~/Library/Application Support/LocationConsole/`。本软件没有账号系统，也没有内置路线或日志上传服务。打开 GPX 绘制网站会访问该外部网站。

原始运行日志可能包含坐标、设备信息或本机路径。提交 Issue 时优先使用「环境检查 → 导出环境报告」，不要上传个人 GPX、设备 UDID、证书或完整原始日志。
