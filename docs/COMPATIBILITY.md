# 兼容范围与验证状态

## 当前发布范围

| 项目 | 范围 |
|---|---|
| Mac 构架 | Apple Silicon，arm64 二进制 |
| macOS | 应用最低加载声明为 14.0；实际还必须满足所用完整 Xcode 的系统要求 |
| Xcode | 必须有 devicectl，完成首次初始化，并提供所需 location coordinate / route / clear 接口 |
| iPhone | USB 连接、解锁、配对并信任 Mac、开发者模式已开启；系统需与所用 Xcode 匹配 |
| 其他平台 | 当前不提供 Windows、Android 或 Intel Mac 二进制 |

环境检查通过是工具和设备准备的检查结果，不等于全部系统组合已经完成真机回放验收。软件按接口能力判断，不靠猜测一个最低 Xcode 版本。

Xcode 对 macOS 和设备系统的要求请查 [Apple Xcode 支持表](https://developer.apple.com/support/xcode/)。不要只依据应用 Info.plist 的最低系统版本安装。

## 已有观察

| 环境 | 已有证据 | 未覆盖 |
|---|---|---|
| Apple Silicon，macOS 27.0，Xcode 27.1，iPhone iOS 27.0 | 底层原生路线接口曾用于真实回放；测得非负系统速度，使用者报告特定 App 累计里程 | 当前 Beta 在另一台干净 Mac 的首次安装体验；其他设备组合的完整回放 |
| 其他 macOS / Xcode / iOS 组合 | 暂未建立兼容结论 | 需使用者实际确认并反馈 |

上述观察不保证第三方 App 当前或未来版本认可轨迹、里程或记录。

## 已知限制

- 回放进度按本机时间估算，不读取手机实际坐标来确认终点。
- 路线接口可提供速度，但速度精度仍可能无效；软件模拟标记仍存在。
- GPS 的 WGS84 与 GCJ-02 / BD-09 坐标不可直接混用。
- 清除成功返回后，仍需在手机上确认真实位置；必要时重启手机。
- 当前发布包临时签名、未公证，其他 Mac 首次启动尚未验收。

## 反馈兼容信息

在软件中导出「环境报告」，加上手机型号、iOS 版本、具体步骤和现象即可。报告默认不含设备名称、UDID、路线坐标或原始运行日志。不要把个人路线或开发证书放进 Issue。
