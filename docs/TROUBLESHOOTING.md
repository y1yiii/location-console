# 常见问题

## 没找到 Xcode

单独的 Command Line Tools 不包含本工具所需的完整开发环境。先安装并打开完整 Xcode；如果装在其他位置，在「环境检查」点击「选择 Xcode」。

## 初始化检查未通过

打开 Xcode，由你本人完成其许可和组件准备，再回到软件重新检查。软件不会自动接受许可、登录账号或安装组件。

## 固定定位通过，路线接口不通过

当前 Xcode 可能没有软件所需的原生路线接口。查看 [Apple 支持表](https://developer.apple.com/support/xcode/)选择适合 Mac 和 iPhone 的 Xcode，然后重新检查。软件不会在这种情况下静默换用旧定位接口。

## 能看到手机，但不能开始

已配对的离线手机也可能出现在列表。检查数据线、解锁、信任和开发者模式，刷新后选择可连接的设备。查看「环境检查」中的 iPhone 开发准备提示。手机重启后可能需要再次解锁或让 Xcode 完成设备准备。

## 读取一直没结束

点击底部「取消读取」，等待返回。刷新完成后有两秒间隔，避免连续请求。若反复超时，打开 Xcode 确认它能看到手机，再重新检查环境。不要同时运行多个定位控制工具。

## 轨迹移动，但运动软件不累计里程

本工具发送定位模拟，不能保证第三方 App 认可记录。App 可能根据系统速度、精度、来源标记或其他数据决定是否计入；仅凭轨迹显示无法判断具体规则。

## 清除后地图仍在模拟位置

区分地图视图停在旧地点和当前位置蓝点没有恢复。点手机地图的「当前位置」确认。可以重新发送清除；仍残留时重启 iPhone，再确认真实位置。拔线或关闭软件不等于已清除。

## 路线库找不到原 GPX

正常情况下不需要原 GPX：软件保存的是自己的坐标副本。如果原文件已移动，点击「我的路线」中的条目即可。若副本损坏，保留数据目录并从原 GPX 重新导入。不要在未清除会话时删除数据目录。

## 提交问题时附什么

优先附「环境检查 → 导出环境报告」、软件版本、复现步骤和错误截图。原始运行日志可能包含坐标、设备信息和路径；不要直接公开上传。报告也请自行检查后再分享。
